# 🕊️ Essência Espírita - Gerador de Textos Simples

Este aplicativo gera textos resumidos baseados exclusivamente na **Doutrina Espírita Kardecista**.

## 🚀 Como Rodar
1. Instale as dependências: `pip install -r requirements.txt`
2. Rode o app: `python -m streamlit run app.py`
3. Insira sua chave do OpenRouter na barra lateral
